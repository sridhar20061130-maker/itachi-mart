ITACHI MART - MOBILE READY PROJECT

This ZIP contains the project source files for the Itachi Mart e-commerce website.

IMPORTANT:
- .env and node_modules are NOT included for security and size reasons.
- Do NOT upload your real MongoDB password to GitHub.
- Use .env.example as a template when running the backend locally.

PROJECT FILES:
index.html       Customer storefront
style.css        Storefront styling
script.js        Storefront JavaScript
admin.html       Admin dashboard
admin.css        Admin styling
admin.js         Admin JavaScript
admin-login.*    Admin login files
server.js        Node.js + Express backend
models/          MongoDB/Mongoose models
assets/          Website image assets
package.json     Node.js dependencies

ON MOBILE:
You can store/extract this ZIP on Android and edit the files with a code editor.
For full Node.js backend development, a PC or a cloud development environment is recommended.
